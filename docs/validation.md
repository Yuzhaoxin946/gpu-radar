# 验证范围

本文记录可复现的验证方法与已覆盖范围，不包含具体部署账户、内部主机或实际监控数据。

## 自动化验证

从项目根目录执行：

```bash
./scripts/test.sh
.venv/bin/python scripts/smoke.py
cd macos && swift test
```

- 后端：账户隔离、账户与设备凭据边界、密码修改和会话轮换、认证竞态、撤销和过期、请求限流、乱序样本、采集错误、五分钟加权统计、精确边界、窗口重置与数据库持久化。
- Agent：真实采集解析、未知指标、进程权限、采集超时、配置文件权限、登录和设备绑定、凭据撤销、中心时间校准、Python 3.6 语法与独立包运行。
- 安装器：下载校验、重复安装、绑定复用、预检不修改安装、账户与服务地址不匹配、linger 或用户管理器失败、更新失败回滚、并发安装和终端输入。
- Swift：API 字段解码、五分钟窗口、固定服务地址和改密请求。

`scripts/smoke.py` 启动临时数据库与本机 API，由实际 Agent CLI 完成登录、登记和上报，验证账户隔离、状态、改密、设备续报、过期与解绑。它仅在隔离测试环境将统计窗口缩短，生产窗口固定为 300 秒。

## 实机验证

- Ubuntu 18.04、Python 3.6.9、8 张 NVIDIA A100-SXM4-80GB：独立 Agent 采集、中心时间校准和真实 HTTPS 上报。
- 用户级 systemd 与 linger：服务处于 active/enabled，结束部署 SSH 后仍持续上报；重启采集服务后恢复上报。
- 原生服务端：systemd、SQLite WAL、Nginx、HTTPS 证书验证、续签演练与一致性备份。
- macOS：Apple Silicon Release 构建、临时签名、登录与注册表单、演示模式、桌面 GPU 详情。菜单栏布局和不可点击方块经过代码审查。
