# 验证范围

本文记录可复现的验证方法与已覆盖范围，不包含具体部署账户、内部主机或实际监控数据。

## 自动化验证

从项目根目录执行：

```bash
./scripts/test.sh
.venv/bin/python scripts/smoke.py
cd macos && swift test
```

- 后端：账户隔离、账户与设备凭据边界、密码修改和会话轮换、认证竞态、撤销和过期、请求限流、乱序样本、采集错误、五分钟加权统计、精确边界、窗口重置与数据库持久化。邀请码测试覆盖缺失或无效邀请码、五次使用上限、多实例并发领取、重复用户名与会话写入失败时回滚、重启后保留名额、管理员重复配置不补充名额，以及已有数据库升级。
- Agent：真实采集解析、未知指标、进程权限、采集超时、配置文件权限、登录和设备绑定、凭据撤销、中心时间校准、Python 3.6 语法与独立包运行。
- 安装器：下载校验、重复安装、绑定复用、预检不修改安装、账户与服务地址不匹配、更新失败回滚、并发安装、终端输入、共享 Home 下的主机隔离和旧版配置保护。覆盖 root / sudo / sudo -u 的有效 UID 与主目录选择，普通用户的 user 服务、root 的 system 服务，以及无 systemd / linger 时自动改用独立进程；重装保留后台模式，停止失败时不替换运行中的程序。
- 独立后台进程：在 Linux 的真实进程与伪终端上验证退出终端、SIGHUP、并发启动、运行锁、PID 复用与旧 boot ID、拒绝停止不明进程、原子升级、启动超时清理、控制锁超时、日志权限和轮换。测试使用临时文件及回环地址，不使用线上账户或修改生产服务。macOS 跳过依赖 Linux `/proc` 的用例。 Agent 与安装器共 92 项测试在 Linux root 环境全部通过；macOS 通过 82 项、跳过 10 项 Linux 专属用例。systemd 操作使用模拟，不代表已重启实机。
- Swift：API 字段解码、五分钟窗口、固定服务地址、改密请求，以及注册请求携带邀请码、登录请求不携带邀请码。一键安装的两种来源、独立登录的主机路径与 Bash 语法、特殊字符的 Shell 转义，以及 AppKit 实际布局下菜单列表在 1 / 2 / 10 / 20 台服务器时的宽度、高度与上限；共 12 项测试。

`scripts/smoke.py` 启动临时数据库与本机 API，由实际 Agent CLI 完成登录、登记和上报，验证邀请码注册、账户隔离、状态、改密、设备续报、过期与解绑。它仅在隔离测试环境将统计窗口缩短，生产窗口固定为 300 秒。

## 实机验证

- Ubuntu 18.04、Python 3.6.9、8 张 NVIDIA A100-SXM4-80GB：独立 Agent 采集、中心时间校准、真实 HTTPS 上报，以及新版安装器的只读预检。
- Ubuntu 22.04、Python 3.10.12、8 张 NVIDIA GeForce RTX 4090、NFS 共享 Home：通过阿里云镜像完成公开安装器的真实终端登录、主机隔离安装、首条上报和后台服务配置；关闭 SSH 后连续观察 35 秒，每 5 秒有新样本。该环境直连 GitHub 超时，GitHub 匿名下载与文件摘要已在开发机验证。
- 用户级 systemd 与 linger：服务处于 active/enabled，结束部署 SSH 后仍持续上报；重启采集服务后恢复上报。
- 原生服务端：systemd、SQLite WAL、Nginx、HTTPS 证书验证、续签演练与一致性备份。
- 线上邀请码注册：缺失或无效邀请码被拒绝；单独的临时邀请码成功注册后耗尽，服务重启后仍被拒绝；测试账户及邀请码已清理，正式邀请码额度未消耗，已有账户与两台 Agent 继续工作。
- macOS：Apple Silicon Release 构建、临时签名、登录与注册表单、演示模式、桌面 GPU 详情。“添加服务器”中的安装来源选择、可复制命令和独立登录展开区域已检查；关闭主窗口后，菜单栏实机显示两台各 8 卡服务器的名称、型号与状态方格。菜单宽度 420 点；10 行高度上限由 AppKit 布局测试覆盖，方格无点击动作。

## macOS 1.0 发行包

- Apple Silicon Release 构建与 12 项 Swift 测试通过。
- 图标源图保留透明背景，构建脚本生成标准尺寸 ICNS，并通过 `CFBundleIconFile` 嵌入签名包。
- `GPU-Radar-1.0.0-macOS-arm64.dmg` 通过磁盘映像校验。只读挂载后核对 App、Applications 链接、中英文安装说明、版本 1.0.0（build 5）、arm64 架构、macOS 13 最低要求、ICNS 尺寸和严格代码签名验证。
- 从挂载的 DMG 启动包内程序，运行 5 秒未退出，随后结束测试进程并推出磁盘；保留原来运行的 App。此检查不代表首次下载时通过 Gatekeeper，也不代表重新执行了真实账户登录。
- 使用 ad-hoc 签名，未进行 Developer ID 签名、Apple 公证或 Intel Mac 实机验证。
