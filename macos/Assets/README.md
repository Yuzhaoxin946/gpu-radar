# GPU Radar app icon

`AppIcon.png` is the source image for the GPU Radar 1.0 icon. It was generated with the built-in imagegen tool. The transparent exterior is preserved. `macos/build-icon.sh` scales this source into the standard macOS icon sizes and creates `AppIcon.icns`; `build-app.sh` includes it in the signed application bundle.

## Generation prompt

Use case: logo-brand. Asset type: final macOS application icon for GPU Radar, a compact GPU server availability monitor. Create one polished square 1024x1024 app icon, not a mockup or presentation. A dark deep navy rounded-square macOS tile centered with a small transparent margin, subtle bevel and refined soft highlights. Inside the tile: a bold mint-green radar sweep and two clean concentric radar arcs integrated with a simple GPU microchip silhouette, with a compact row of three luminous square status cells (green, amber, coral red) as the distinctive GPU occupancy motif. Elegant restrained dimensional finish, very legible at 32px, generous negative space, strong simple silhouette, crisp edges. No letters, no words, no numbers, no surrounding objects, no watermark. True transparent exterior outside the rounded-square tile. The tile should occupy about 88 percent of canvas width and height.
